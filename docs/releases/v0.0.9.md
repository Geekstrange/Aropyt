# 警报块与侧栏记忆

> 支持 GitHub 风格的 `[!NOTE]` 等警报块；侧栏开合状态现在会被记住。

Aropyt **v0.0.9** · 2026-10-20

## 更新内容

### Markdown：GitHub 风格警报块

支持五种类型，各有专属颜色与图标：

```markdown
> [!NOTE]
> 补充说明。

> [!TIP]
> 更省事的做法。

> [!IMPORTANT]
> 完成任务前必须知道的信息。

> [!WARNING]
> 需要立即注意的内容。

> [!CAUTION]
> 提醒某操作的负面后果。
```

编辑器里直接呈现为带左侧色条、类型色标题与图标的块 —— 深浅主题各有对应配色。

### 侧栏会记住你的选择

关掉侧栏后重启，它保持关闭。状态写回 `settings.jsonc`，与其它设置同源。

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`
- **Android**：`.apk`（正式签名，Android 10+）

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 已知限制

- 警报块的标题为英文（Note / Tip / …），与 GitHub 行为一致
- 多语言界面暂未提供（已跳票，不再承诺具体版本）
