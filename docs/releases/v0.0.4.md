Aropyt v0.0.4 —— Typora 式 Markdown 编辑器。

## 本次更新

### Vim 模式打磨

- **normal 模式不再误删字符**：Backspace / Delete 交给 vim，不进插入模式不会改动文本
- **vim 模式恒为源码态**：渲染态下整块 Markdown 只是一个 DOM 块，行级光标无处可落（j/k 会跳过整段文字）—— vim 下隐藏源码模式按钮、`Ctrl+/` 不响应，退出 vim 自动回到渲染态
- **子模式指示**：状态栏显示 `NORMAL` / `INSERT` / `VISUAL`，随时知道自己在哪个模式
- **vim 下宿主快捷键照常可用**（`Ctrl+Shift+B` / `Ctrl+Shift+N` / `Ctrl+Tab` / `Ctrl+0`）
- **禁用鼠标拖选**：单击定位光标可用，拖选 / Shift 扩选被拦

### 快捷键与交互

- `Ctrl/Cmd+Shift+B` 开关侧栏 ｜ `Ctrl/Cmd+Shift+N` 新建标签 ｜ `Ctrl/Cmd+Tab` 切换标签（Shift 反向）｜ `Ctrl/Cmd+0` 聚焦侧栏
- 快捷键与 vim 不冲突：`Ctrl+B`（翻页）与 `Ctrl+N`（补全）留给了 vim
- `Ctrl+F` / `Ctrl+H` 搜索面板重新设计：中文化、无圆角、贴合主题的输入框与匹配高亮；vim 模式下不抢占
- **鼠标中键点击标签**即可关闭
- **侧栏开关会被记住**，下次启动保持你的选择
- 源码模式按钮如实显示当前模式（vim 下自动隐藏）

### 视觉

- 渲染态行距收紧（行高 1.8 → 1.55，段落与标题间距同步缩小），更接近 Typora 的排版密度
- 源码模式按钮的开启态有主色描边（此前只有细微背景差，看不出在哪一模式）
- 状态栏与关于对话框的版本号改为构建时注入，不再硬编码

### 插件

- 插件管理面板：查看已导入插件，可启用 / 禁用（禁用立即生效并记住）
- 导入插件：选择一个 `.js` 文件即可（导出 `manifest` + `activate`）

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。
