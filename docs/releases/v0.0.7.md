Aropyt v0.0.7 —— Typora 式 Markdown 编辑器。

## 本次更新（v0.0.7：编辑历史 + 数据备份）

### 编辑历史

- **保存即版本**：每次保存自动记录一个版本（内容未变不重复记录）
- **自动保存版本**：可设间隔（默认 60 秒），写作途中不怕崩
- **手动命名版本**：给重要节点留个里程碑
- **一键恢复**：恢复前自动把当前内容存为"恢复前快照"，任何操作都不丢内容
- 每个文件保留最近 N 个版本（默认 50，可在设置调整），更早的自动淘汰
- 工具栏新增编辑历史入口，版本列表显示时间 / 标签 / 大小
- 单版本上限 4MB；写入原子化，断电不留半截数据

### 数据导出 / 导入

- 设置面板新增「数据备份」：一键导出**全部草稿与编辑历史**为单个 JSON
- 导入会覆盖现有数据（导入前有明确警告与数量确认）
- 用途：换机器、重装系统、跨平台迁移、备份存档
- 文件可读可手工修，与系统路径完全解耦

### 其他

- 修复 CI：Windows/macOS/Linux 三平台构建恢复
- 工具栏新增编辑历史图标

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 已知限制

- 历史面板暂不显示**版本间 diff**（下一版加入）
- 编辑历史的自动保存间隔最短 15 秒
- `.tex` / `.fountain` 渲染需插件支持（后续版本）
