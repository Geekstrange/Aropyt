Aropyt v0.0.1 —— Typora 式 Markdown 编辑器。

## 亮点

- **块级所见即所得**：编辑区即预览，与预览共用同一渲染引擎
- **代码块语法高亮**：highlight.js 常见语言开箱即用
- **Mermaid 图表**：流程图 / 时序图 / 类图 / 思维导图直接渲染成 SVG
- **Vim 模式**：normal / insert / visual，状态栏一键开关
- **轻量**：首屏 ≤ 300KB，长文档虚拟化滚动

## 安装

- **Windows**：下载 `*-setup.exe`（推荐）或 `.msi`
- **macOS**：下载 `.dmg`（Apple Silicon 选 aarch64）
- **Linux**：下载 `.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。
