Aropyt v0.0.2 —— Typora 式 Markdown 编辑器。

## 本次更新

### 数学公式渲染（新）

- 支持 `$…$` / `$$…$$` 与 `$…$` / `$$…$$` 四种定界符（行内 + 块级）
- KaTeX 排版：分数、根号、求和积分、矩阵、`aligned` / `cases` 环境、`\tag` 编号、`\mathbb` / `\partial` 等全套数学语法
- 按需加载（公式出现时才下载引擎与字体），不影响首屏
- 代码块与行内代码里的 `$` 不会被误判为公式

### 未保存修改关闭提示（新）

- **关闭标签**：有未保存修改时确认 ——「不保存并关闭」/「保存并关闭」/ 取消
- **关闭软件**：拦截窗口关闭并确认 ——「保存并退出」/「不保存退出」/ 取消
- 草稿全程自动保存，误操作可恢复

### 修复

- 块级数学中以 `+` / `-` / `*` / 数字开头的 tex 行不再被误解析为列表（整块退化成文本的问题）
- Mermaid 语法错误不再静默：显示具体错误原因
- 彩色状态图改用 flowchart 表达（stateDiagram 不支持 classDef 着色）

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。
