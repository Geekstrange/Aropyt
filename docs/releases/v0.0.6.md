Aropyt v0.0.6 —— Typora 式 Markdown 编辑器。

## 本次更新（v0.0.6：文件关联）

### 双击打开文件

- 安装版会注册 **Markdown（.md / .markdown）**、**LaTeX（.tex / .latex）**、
  **Fountain 剧本（.fountain）** 三种文件类型
- 双击文件即可用 Aropyt 打开；也支持命令行：`Aropyt.exe note.md`
- 类型图标各自独立（Markdown / LaTeX / Fountain 三种图标）
- 卸载时会清理本应用写过的关联（且只在默认程序指向自己时才清）

### 外部文件编辑

- 通过关联打开的文件可以**直接编辑并保存回原位置**（Ctrl/Cmd+S）
- 单文件上限 8MB；写入是原子的（临时文件 + 重命名），断电不留半截文件

### 说明

- 文件关联由安装器写入，**免安装的 exe 不会注册**（但可直接用命令行传路径）
- 若 `.md` 已被其他编辑器占用默认程序，图标可能仍显示那个应用的；
  在系统设置的"默认应用"里选 Aropyt 即可

## 安装

- **Windows**：`*-setup.exe`（推荐，文件关联只由它注册）
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 已知限制

- **应用已运行时**再次双击文件不会在现有窗口打开（需要单实例转发，下一版）
- `.tex` / `.fountain` 目前只做关联与打开，**渲染需插件支持**（后续版本）
- 编辑历史（v0.0.7）尚未提供
