# Aropyt v0.1.8 — Take It Somewhere


This release has one new capability and three bugs that only surface after
you have been writing in the same window for an hour.

## Export

The toolbar now has an **Export…** button, right next to Save. Pick a format,
pick a location, and pandoc does the conversion:

| Format | Opens in |
| --- | --- |
| `.docx` | Word / WPS / Pages |
| `.pdf` | via **typst** |
| `.html` | any browser |
| `.odt` | LibreOffice |
| `.epub` | e-readers |
| `.rtf` | legacy word processors |

**Content goes in over stdin**, never through a temp file — no path escaping,
no encoding surprises, and nothing left on disk when a conversion fails.
`--resource-path` points at the workspace root, so `![](assets/a.png)`
survives into the docx instead of arriving as a broken image. A conversion
that fails reports **pandoc's own stderr** verbatim: "line 207: file not
found" is worth ten of "Export failed".

**PDF runs typst.** Engines are never bundled — you install pandoc and typst
yourself, and the app only probes for them. A missing typst disables PDF
alone; every other format keeps working. The check runs *before* the save
dialog, because a late failure would already have created a 0-byte file.

Three bugs came out of building that path, and all three were reproduced
before being fixed:

- **`--pdf-engine` with an absolute path breaks typst.** pandoc invokes the
  engine with a `\\?\` long-path prefix; typst then treats images it cached
  under `%TEMP%\media-<hash>\` as *relative* paths and dies with
  `path contains invalid component "C:"`. This is also why English documents
  exported fine — no images, nothing to resolve. The engine's directory is
  now prepended to the child PATH and the bare name is passed.
- **Local drive-letter image paths** are rewritten to `file:///` URLs before
  PDF export, backslashes and all. PDF only: a `file:///` link inside a docx
  handed to a colleague is worse than useless.
- **`.tex` documents were read as markdown**, so `\documentclass`,
  `\section` and `\begin{}` were swallowed and a 66-line file exported as a
  single comment line. `--from` now follows the document, and latex sources
  get `--number-sections` — `\ref{}` becomes a typst `@label` reference, and
  typst refuses those without heading numbering. Same file: 7 984 bytes →
  56 788 bytes.

Settings gained an **Export tools** section: two Browse buttons, the detected
version live next to each, and an immediate re-probe. Changing a path should
not require restarting the app.

## Bugs that only show up after hours of writing

**Backspace deleted an entire block.** A rendered block is one indivisible
replacement range, so no cursor fits inside it; a cursor hugging the boundary
made CodeMirror treat the whole block as a single character. Task lists made
it obvious, but paragraphs, headings and code blocks behaved the same way.
The test is positional now (`head ∈ [from−1, to+1]`) rather than per-line.
The `to` side needs the extra position because node ranges include the
trailing newline — "cursor at the start of the blank line after the block"
is exactly the spot that ate the list.

**Ctrl+Z after switching documents restored the previous document.** The
full-text replace that loads a document was itself an undoable transaction,
so undo replayed "A → B" backwards — and kept going back through every
earlier document. It now carries a history barrier and is excluded from the
undo stack. Undo *inside* a document still works.

**A single newline inside a paragraph renders as a line break.** The
two-trailing-spaces rule never held in practice: the sample document's own
line about it ends with `。` on disk — whitespace does not survive save,
`git commit` or paste. `breaks: true` matches how GitHub renders issue
bodies, and list continuations get the same treatment.

## Fountain title pages

Scripts now open with a real cover instead of a list of `Title:` / `Credit:`
keys:

- Only the eight keys in the spec are recognised, so a line like
  `Name: Alice` inside a scene is no longer mistaken for cover metadata.
- A key may carry no value on its own line — `Notes:` followed by indented
  lines is absorbed into the cover. Those continuation lines used to fall
  through to action, where `FINAL PRODUCTION DRAFT` (all caps) could be taken
  for a character name and turn the rest of the script into dialogue.
- **Key names are hidden**: the page shows `Big Fish` / `written by` /
  `John August`. The prefix comes back while the cursor is inside it, so
  editing still works, and Backspace there cannot delete it as a unit.

## Smaller things

- **`Ctrl/Cmd+Shift+O`** opens a workspace, through the same command and
  error reporting as the toolbar button.
- **The file tree is usable from the keyboard.** Tab or click into it, then
  ↑/↓ to move and Enter to open. The cursor survives the tree being rebuilt
  after each file open, and the indicator is a quiet 2px inset bar rather
  than an outline box.
- **Word count follows Typora's definition**: English words plus CJK
  characters for "words", non-whitespace characters for "characters". The
  status bar used to count English words and CJK characters separately.

## Under the hood

- 15 command functions that every plugin had already replaced with the
  `EditorApi` are gone (`commands.ts`: 216 → 116 lines).
- The seven hand-drawn 16-unit icons were all unreferenced; `icon/*.svg` is
  now the only icon source.
- `installGlobalGuards` runs at startup (observe-only, recorded to the
  operation timeline), `onIdle` preloads katex and mermaid, `safeJsonParse`
  replaced two bare `JSON.parse` sites, and the diagnostics report gained a
  "failed actions" section that pulls failures out of the 30-line timeline.

## Upgrading

Nothing to migrate. Two things worth knowing:

- **pandoc is required for export; typst is required only for PDF.** Neither
  ships with the app. Set their paths in Settings → Export tools if they are
  not on your PATH.
- **CJK PDFs may need a font.** pandoc's typst template uses a Latin default;
  if Chinese text comes out as boxes, a `mainfont` is needed — this release
  does not expose that setting yet.
