# Aropyt v0.1.0 — 插件系统

## 插件系统（本次发布的主体）

### 完整的贡献点

| 贡献点 | 说明 |
| --- | --- |
| `commands` | 声明即出现在命令面板；可同时挂到工具栏 |
| `keybindings` | 按 VSCode 写法声明（`Mod-Shift-D`），宿主负责翻译成编辑器键位 |
| `menus` | 把命令挂到 `toolbar` 等菜单位置 |
| `views` | 在侧栏注册面板，`render(container)` 自己画内容 |
| `configuration` | 声明配置项 → 设置页「插件配置」自动渲染，插件可读写 |

### 命令面板（`Ctrl/Cmd+Shift+P`）

插件可以声明几十条命令，不必挤在工具栏上。面板支持搜索、方向键选择、回车执行，右侧显示绑定的快捷键。

### 插件管理面板

工具栏的插件按钮打开列表：图标、名称、状态（已启用 / 已禁用 / 加载失败 / 未激活）、版本、失败原因，以及启用 / 禁用 / 删除。禁用与删除在重启后生效。

### 容错

插件系统有五层防线，**一个坏插件不会拖垮应用**：

1. **导入时校验** —— `contributes` 结构不合法直接拒绝，并说明原因
2. **加载时逐个隔离** —— manifest 非法的插件被跳过，不影响其它插件
3. **贡献声明时逐个隔离** —— 单个插件的非法声明只标记它自己
4. **激活后校验** —— 声明的命令若没有真的注册上，标记「加载失败」并列出命令名
5. **安全模式** —— `?safe` 启动时禁用全部插件

内置功能（文件树、大纲、格式化、文件操作）与外部插件完全隔离：插件出错时工具栏、侧栏、文件操作照常。

### 开发

插件是单个 `.js` 文件（ES 模块），导出 `manifest` 与 `activate`。完整规范见 README 的 **Plugin development** 一节，可直接参考 `test/sample-plugin.js`（覆盖全部五个贡献点 + 生命周期 + 错误边界）。

## 其他

- 工具栏图标统一（源码模式、编辑历史、插件管理）
- 设置面板新增「插件配置」区
- 排版：行高 1.2、空行压缩到 0.1em（光标所在空行不压缩）
- CSP 放开网络图片与音视频

## 已知限制

- 插件为**单文件**，不能用 npm 依赖（复杂插件需自行打包）
- 插件代码与应用**同进程**运行，没有沙箱 —— 只安装可信来源的插件
- 暂不支持**热重载**：修改插件后需在插件面板重新导入并重启
- `views` 目前验证了 `sidebar` 位置；`main` / `right` 尚未验证
- 生产版没有开发者工具，插件错误详情通过插件面板的原因字段查看

## 升级说明

从 v0.0.x 升级无需迁移：配置文件、草稿与编辑历史格式未变。已导入的插件保持启用状态；若某个插件在 v0.1.0 下显示「加载失败」，面板会给出具体原因。
