# Aropyt v0.1.2 — Edit History Diff

Line-level diff for edit history, plus a batch of fixes accumulated since v0.1.1.

## What's new

### Edit History Diff

Open **Edit History** (`Ctrl+Shift+G`) → each version has a **Compare** button. The diff is computed against the current document.

- **Unified view** — four columns: old line number / new line number / sign / content
- **Split view** — two equal-width columns with a fixed divider; long lines scroll horizontally inside each column instead of crossing the midline
- Empty side rows in Split view use 45° hatched fill
- Header shows file name, `+N / −N` stats, and a Unified / Split toggle
- Diff engine: line-level LCS (`apps/web/src/lib/diff.ts`); each line keeps both its old and new line number

## Fixed

- **`Ctrl+F` did nothing** — `search()` extension was installed but no `Mod-f` binding existed. Now bound explicitly to `openSearchPanel`.
- **WebView native find hijacked `Ctrl+F`** — the browser-level find bar consumes the shortcut before the DOM. Intercepted in the capture phase and forwarded as an app event, since CM6's keymap skips `defaultPrevented` events.
- **vim `:wq` did not save and close** — three separate root causes fixed in sequence: the command was unregistered; `:wq` resolves as `write` + argument `q`; and saving is async while closing was synchronous (save-then-close race triggered an "unsaved" prompt). `onSaveRequest` now returns a `Promise`.
- **File-tree focus never landed on the tree** — `stopPropagation` in the capture handler swallowed the event; the focused element lacked `tabindex`; and the query selector matched the outer `.view-body` container rather than the tree. Focus now lands correctly and `j/k/Enter` navigate.
- **Status bar** — document stats moved to the right, version info moved to Settings › About; runtime metrics live only in the Debug panel.
- **Debug panel** — log search, full error stacks, settings snapshot in the report, `[timeline]` markers for open/close/new-tab.
- **macOS DMG reported as "damaged"** (#1) — `Contents/_CodeSignature/CodeResources` was missing from the bundle, so Gatekeeper treated it as corruption rather than an unsigned app. Ad-hoc signing is now enabled (`bundle.macOS.signingIdentity = "-"`) so the built `.app` carries a complete signature, and CI fails the build when `codesign --verify --deep --strict` rejects it. **Re-install from this release if you hit the issue on v0.1.0–v0.1.2.**

## Known limitations

- The diff view compares a history version against the current document only — comparing two history versions is not supported yet.
- `:q` closes the current tab, not the whole application (consistent with the tab model).
- Heap memory depends on `performance.memory` (may display `—` on WebView2).
