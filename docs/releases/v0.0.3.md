Aropyt v0.0.3 —— Typora 式 Markdown 编辑器。

## 本次更新

### 插件生态第一步

- **插件管理面板**（工具栏插件图标）：列出已导入插件，支持启用 / 禁用
  - 禁用立即生效（撤销该插件的命令与视图），并记住选择
  - 内置功能（文件 / 格式化 / 文件树 / 大纲）不再混入插件管理
- **导入插件**：选择一个 `.js` 插件文件即可（导出 manifest + activate），存储于本地，重启后加载并生效
- 插件可贡献命令、工具栏按钮、视图、键位 —— 与内置功能同等能力
- 示例插件见仓库 `test/sample-plugin.js`（插入当前日期）

### 公式快捷插入

- 工具栏新增公式按钮：插入块级公式 `$$ … $$`
- 有选区时把选中内容直接包成公式块

### 修复

- 关闭**非激活但已修改**的标签时，未保存确认不触发（会静默丢内容）

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 插件信任说明

插件代码在渲染进程内以完整权限运行（与 VS Code 插件同一信任模型，非沙箱）。请只导入你信任的插件。
