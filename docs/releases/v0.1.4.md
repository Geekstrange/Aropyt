# Aropyt v0.1.4 — Small Fixes

No new features. Four corrections since v0.1.3.

## Fixed

**Desktop icon looked undersized.** Running `npx tauri icon` to repair the
Android icon also rewrote the desktop PNGs, padded to the mobile safe-area
ratio — the artwork covered roughly 80% of the canvas. Desktop icons are
rendered edge to edge again.

**Language preference was never read back.** `settings.jsonc` stored
`"locale"` correctly, but the loader validated the default value instead of
the parsed one, so the setting had no effect and every restart returned to
"follow system". The value is now read and validated against a whitelist.

**Source-mode toggle was hard to read.** The pressed state used link blue,
which looks like a hyperlink in light themes rather than an engaged switch.
It now uses the body colour with a brand-tinted background.

**APK still showed the Tauri icon.** The bundled icons have been correct
since v0.1.3. A build that still shows the default icon is reusing an
existing `src-tauri/gen/android` directory — Tauri copies
`icons/android/mipmap-*` into it only when the project is first generated.
Run `npx tauri android clean` before rebuilding. Reinstall the APK after
that; the icon is written at compile time.

## Known limitations

Unchanged from v0.1.3.
