# Aropyt v0.1.3 — Eight Languages, and a Portrait Layout That Works

The UI is now fully translated into eight languages, and the layout adapts
down to phone-sized screens instead of falling apart below 900px.

## What's new

### Eight interface languages

Chinese, English, German, French, Japanese, Korean, Italian and Russian —
223 keys each, selectable from **Settings › Language** as a row of flags
(plus a globe for "follow system").

- `apps/web/src/i18n/` — `t()` is a plain function over module-level state,
  not a React hook. Runtime messages, command registration and plugin code
  all need text outside the component tree, so a Context provider was not
  viable. Components subscribe via `useSyncExternalStore` instead.
- `TextKey = keyof typeof zh`, and every dictionary is typed as
  `Record<TextKey, string>` — a missing key fails the build rather than
  silently falling back at runtime.
- The initial locale resolves at module load (`detectLocale()`) rather than
  defaulting to Chinese. Imperative views render once during runtime creation
  and would otherwise be stuck with the wrong language.
- `Settings › Language` uses each language's endonym as `aria-label`
  ("Deutsch", not "German").
- Command palette titles and category prefixes (`File:` / `Format:`) are
  translated at render time. Plugins declare those strings in a module-level
  manifest, where calling `t()` would capture whichever language happened to
  be active at import.

### Portrait layout

The app was designed for a desktop window; below 900px the sidebar took 240px
of a 400px screen and the toolbar simply cut off its last ten buttons.

| Width | Behaviour |
|---|---|
| > 900px | Sidebar occupies layout width; open/closed state persists to settings |
| ≤ 900px | Sidebar becomes an overlay, **closed by default**; toggling it no longer writes to settings |
| ≤ 1200px | Toolbar wraps to a second row instead of scrolling horizontally with its scrollbar hidden |
| ≤ 640px | Status bar keeps word count and drops secondary items; settings/history/command panels go full-screen |

- The open/closed state of the sidebar now follows a responsive
  `matchMedia` subscription. The previous `isWideScreen()` read the width once,
  so dragging a window across the breakpoint never updated it.
- On narrow screens the status bar drops its flex spacer. Pushing the stats to
  the right with `margin-left: auto` was unreliable: once content exceeded the
  container, `overflow: hidden` clipped from the right and the word count — the
  most useful item — disappeared first.

## Fixed

- **APK still shipped the Tauri logo.** `scripts/make-icons.mjs` only writes
  desktop icons (PNG/ICO/ICNS plus the Windows Store set) and never touched
  `src-tauri/icons/android/`, which still held the icons generated by
  `tauri init`. Mobile assets — five densities of `ic_launcher` /
  `ic_launcher_round` / `ic_launcher_foreground`, plus the
  `mipmap-anydpi-v26` adaptive-icon layers — are now generated with
  `npx tauri icon logo.svg`. **Reinstall the APK to pick it up.**
- Flag icons rendered blank for German, Italian, Russian and Korean. Each
  source SVG has its own coordinate space (`gb` is `0 0 60 30`, `de` is
  `0 0 5 3`, `kr` is `-72 -48 144 96`); pinning them all to `0 0 900 600`
  shrank the artwork into a corner. Each flag now keeps its own `viewBox`.
- Several flags share `id="a"` for reusable shapes. Inlined side by side they
  collided, so every SVG id carries a locale prefix.
- The selected language was always reported as "system". `RuntimeState.locale`
  read from `configuration`, while `updateSettings()` writes `currentSettings`
  — two separate stores. Only the globe was ever highlighted.
- Outline and file-tree empty states kept the previous language after a switch.
  Views are rendered imperatively by plugins, so they are now torn down and
  rebuilt when the locale changes.

## Known limitations

- Third-party plugins are not translated. Only built-in command titles and
  categories are mapped, so an external plugin's own labels stay as authored.
- Internal log lines (`[aropyt]`, `[plugins]`), manifest validation errors and
  the debug report template remain in Chinese — their audience is developers,
  and the Chinese keywords are what makes them greppable.
- Toolbar buttons are roughly 26×26px even on touch screens, below the 44px
  recommended target. Making them larger would push the toolbar back to three
  rows on a phone.
