Aropyt v0.0.5 —— Typora 式 Markdown 编辑器。

## 本次更新（v0.0.5：设置）

### 设置面板

- 工具栏新增**设置**入口（齿轮图标），面板分为外观 / 编辑 / 配置文件三区
- 深浅模式切换（浅色 / 深色 / 跟随系统）从工具栏移入设置
- Vim 模式开关可在设置里直接切换

### 配置文件 settings.jsonc

- 用户配置落在 **`~/.aropyt/settings.jsonc`**（家目录，可手改、可备份、可纳入版本控制）
- **JSONC 格式**：允许注释与尾逗号 —— 手改时能写"为什么这么设"
- 配置项：`theme` / `editor.fontSize` / `vim.enabled` / `sidebar.open` /
  `plugins.disabled` / `history.limit`（编辑历史预留）
- **配置即真源**：主题、vim、侧栏、插件禁用均由它派生；界面里的修改立即写回文件
- 首次启动会把旧的本地存储设置迁移进配置文件（只做一次）
- 手改出错有反馈：未知键与非法值都会在启动时提示，不会静默忽略
- **原子写**（临时文件 + 重命名），断电不会留下半截配置
- 设置面板里可一键用系统默认程序打开配置文件

### 标签栏修复

- **鼠标中键**点标签即可关闭（此前被浏览器"自动滚动"抢走事件）
- 标签过多时**滚轮可横向翻标签**（滚动条隐藏，滚轮补偿）
- 标签溢出不再把右侧按钮挤出窗口

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`
> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 已知限制

- 双击 `.md` 用 Aropyt 打开**暂不支持**：尚未实现命令行参数处理与文件关联，
  请先在应用内打开工作区。该功能在下一版。
- 编辑历史（v0.0.6）尚未提供。
