# Android 正式版

> 首次提供正式签名的 Android 安装包；源码模式现在能看见空白字符。

Aropyt **v0.0.8** · 2026-10-19

## 更新内容

### Android 正式签名包

- 首次提供**正式签名的 APK**（此前只有 debug 签名的调试包）
- 安装包图标改为 Aropyt（不再是 Tauri 默认图标）
- 修复内容顶到状态栏下的布局溢出（fitsSystemWindows）
- 支持 Android 10+ / arm64 设备

> 若装过旧的 debug 版 APK，需先卸载再安装（签名不同）。

### 源码模式：看得见的空白字符

`Ctrl+/` 进入源码模式后：

- **空格**显示为浅色中点
- **制表符**显示为向右箭头
- 控制字符显示为转义符号

专为排查缩进错、对齐错而做 —— 源码模式本来就该是"排障模式"。

### 界面

- 工具栏图标更新：设置、插件管理、源码模式
- 设置面板的标题栏固定，只有内容滚动
- 修正配置区一段过时的说明文字

### 其他

- 修复发布流程的 tag 错位问题（rc 与正式版不再混淆）
- Windows MSI 安装包支持中文（此前安装器与类型名编码受限）

## 安装

- **Windows**：`*-setup.exe`（推荐）或 `.msi`
- **macOS**：`.dmg`（Apple Silicon 选 aarch64）
- **Linux**：`.AppImage`（免安装）或 `.deb`
- **Android**：`.apk`（正式签名，Android 10+）

> macOS 未签名，首次打开需右键 → 打开，或到系统设置放行。

## 已知限制

- 多语言界面暂未提供（已跳票，不再承诺具体版本）
- 历史面板暂不显示版本间 diff
- `.tex` / `.fountain` 渲染需插件支持
